# 🌿 Diarista — Controle Financeiro

App para controle de pagamentos de diarista com suporte a diárias, adiantamentos, competências e relatórios.

**Dados:** armazenados exclusivamente no localStorage do dispositivo. Nenhum dado é enviado para servidores.

## Deploy

Hospedado via [Cloudflare Pages](https://pages.cloudflare.com) a partir deste repositório.

## Uso local

Abra `index.html` diretamente no navegador — não precisa de servidor.

## Backup

Use o botão **⬇ Backup** no app para exportar um `.json` e **⬆ Importar** para restaurar em outro dispositivo.
